# Зауваження до початкового коду

| № | Місце в початковому коді | Зауваження |
| --- | --- | --- |
| 1 | `Triangle(double a, double b, double c)` | Конструктор `Triangle` не перевіряє, що сторони додатні. |
| 2 | `Triangle(double a, double b, double c)` | Конструктор допускає `NaN` і нескінченні значення сторін. |
| 3 | `Triangle(double a, double b, double c)` | Не перевіряється нерівність трикутника. |
| 4 | `Triangle()` | Порожній конструктор створює трикутник із нульовими сторонами. |
| 5 | `putA`, `putB`, `putC` | Сетери дозволяють змінити сторони так, що трикутник перестане існувати. |
| 6 | `takeA`, `takeB`, `takeC` | Гетери `takeA`, `takeB`, `takeC` краще назвати `getA`, `getB`, `getC`. |
| 7 | `perim` | Назва `perim` незрозуміло скорочена; краще `perimeter`. |
| 8 | `equilateral` | Булевий метод `equilateral` краще назвати `isEquilateral`. |
| 9 | `equilateral` | В `equilateral` зайва конструкція `if/else`: можна одразу повернути результат умови. |
| 10 | `area` | В `area` чотири рази обчислюється той самий півпериметр. |
| 11 | `Triangle.java` | У `Triangle.java` непослідовні відступи та пробіли. |
| 12 | `Triangle.java` | Не описано вимоги до сторін і поведінку при некоректних значеннях. |
| 13 | `Main.java` | `Main` не використовує `Triangle`, а лише виводить привітання та числа. |
| 14 | `Main.java` | `String.format` у `Main` викликається без параметрів форматування. |
| 15 | `Main.java` | У шапці `Main` залишено шаблонну назву проєкту та незаповнене поле `${NAME}`. |
